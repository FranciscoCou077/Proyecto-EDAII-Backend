	\section{Descripción General del Proyecto}
	% ============================================================
	El \textbf{Visualizador Interactivo de Algoritmos} es un sistema web interactivo diseñado como proyecto final de la materia \textit{Estructura de Datos y Algoritmos II}. Su propósito es doble: servir como herramienta de visualización pedagógica para estudiantes de ingeniería y como demostración de arquitectura de software moderna aplicada al ámbito académico.
	
	El sistema integra tres componentes desplegados de forma independiente en producción:
	
	\begin{itemize}[noitemsep]
		\item \textbf{Backend API REST} desarrollado en Python con FastAPI, que implementa y expone todos los algoritmos del temario de la materia.
		\item \textbf{Interfaz Gráfica Web} desarrollada en React + Vite con estética Frutiger Aero, que permite la interacción visual con los algoritmos.
		\item \textbf{Chatbot RAG (Asistente IA)} basado en LangChain + Groq, que responde preguntas sobre los algoritmos implementados en el proyecto utilizando el código fuente del backend como base de conocimiento.
	\end{itemize}

	\subsection{Chatbot RAG}
	El chatbot utiliza la técnica de \textbf{Retrieval-Augmented Generation (RAG)}:
	\begin{enumerate}
		\item Al recibir una pregunta, clona la rama \texttt{dev} del repositorio backend.
		\item Carga los archivos \texttt{.py} de la carpeta \texttt{app/algoritmos/} con \texttt{DirectoryLoader}.
		\item Realiza búsqueda por palabras clave con normalización (camelCase, traducciones español $\to$ inglés, variaciones con guion bajo).
		\item Pasa los fragmentos relevantes como contexto al LLM (Groq \texttt{llama-3.1-8b-instant}).
		\item Retorna la respuesta al frontend vía \texttt{POST /preguntar}.
	\end{enumerate}
	
	\subsection{Frontend}
	Interfaz de una sola página (SPA) con:
	\begin{itemize}[noitemsep]
		\item Navegación por secciones: Inicio, Algoritmos, Documentación, Nosotros, Asistente.
		\item Índice Temático Interactivo con Scrollspy de Bootstrap.
		\item Visor de PDF embebido con navegación por temas.
		\item Ventana de chat flotante conectada al chatbot en tiempo real.
		\item Estética Frutiger Aero con animaciones y música de fondo.
	\end{itemize}

	\section{Proceso de Desarrollo e Integración Backend–Chatbot}
	% ============================================================
	El desarrollo del chatbot implicó una colaboración directa entre los equipos de Backend y Chatbot para lograr la integración funcional del sistema RAG. A continuación se documenta el proceso de cambios técnicos realizados:
	
	\subsection{Migración de LLM: Google Gemini $\to$ Groq}
	El LLM original (\texttt{ChatGoogleGenerativeAI} con \texttt{gemini-1.5-flash}) fue reemplazado por \texttt{ChatGroq} con \texttt{llama-3.1-8b-instant} debido a restricciones de red en Render (plan gratuito) que bloqueaban las conexiones salientes hacia las APIs de Google. El modelo \texttt{llama3-8b-8192} fue descontinuado por Groq durante el desarrollo, migrándose a \texttt{llama-3.1-8b-instant}.\\
	\textbf{Archivo modificado:} \texttt{chatbot\_logic/chain.py}
	
	\subsection{Migración de Loader: GenericLoader $\to$ DirectoryLoader}
	\texttt{GenericLoader.from\_path} no está disponible en la versión de \texttt{langchain-community} desplegada. Se reemplazó por \texttt{DirectoryLoader} con \texttt{PythonLoader}, que carga directamente todos los archivos \texttt{.py} de forma recursiva sin dependencias de parsers adicionales.\\
	\textbf{Archivo modificado:} \texttt{chatbot\_logic/loader.py}
	
	\subsection{Eliminación de ChromaDB como vector store}
	La dependencia de ChromaDB requería credenciales para los embeddings que no estaban disponibles en el entorno de Render. Se reemplazó el sistema de recuperación vectorial por una \textbf{búsqueda directa por palabras clave} sobre los documentos cargados en memoria, con caché de sesión para evitar clonar el repositorio en cada petición.\\
	\textbf{Archivo modificado:} \texttt{chatbot\_logic/retriever.py}
	
	\subsection{Mejoras al sistema de búsqueda}
	\begin{itemize}[noitemsep]
		\item \textbf{Normalización de camelCase}: \texttt{MergeSort} $\to$ \texttt{merge\_sort} mediante expresiones regulares.
		\item \textbf{Diccionario de traducciones español $\to$ inglés}: permite consultas en español que encuentren código en inglés.
		\item \textbf{Búsqueda en metadata de archivos}: además del contenido, se busca en el nombre del archivo fuente (\texttt{source}).
		\item \textbf{Variaciones de separadores}: genera variantes con espacio, guion bajo y sin separador.
	\end{itemize}
	
	\subsection{Actualización de dependencias}
	\begin{lstlisting}[language=bash]
		langchain-google-genai  ->  langchain-groq==0.2.0
		llama3-8b-8192          ->  llama-3.1-8b-instant
		GenericLoader           ->  DirectoryLoader + PythonLoader
		ChromaDB (vectores)     ->  Busqueda por palabras clave en memoria
	\end{lstlisting}

	\section{Advertencias Críticas y Prevención de Fallos}
	% ============================================================
	
	\begin{tcolorbox}[colback=lightgray, colframe=primary, title=\textbf{5.1 Advertencias Lógicas (Degradación de servicio)}]
		Estas condiciones no interrumpen el sistema pero pueden afectar la calidad de las respuestas o el rendimiento de la plataforma:
		\begin{itemize}
			\item \textbf{Respuesta incompleta del Chatbot:} El bot responde "no tengo información" sobre un algoritmo existente. \textit{Causa:} La consulta usa términos no cubiertos por el diccionario de traducciones o el retriever no encontró coincidencias.
			\item \textbf{Latencia alta en el primer arranque:} La primera respuesta del chatbot tarda 60–90 segundos. \textit{Causa:} El servicio de Render (plan gratuito) se duerme tras 15 minutos de inactividad; el tiempo de arranque frío incluye clonar el repositorio de GitHub completo.
			\item \textbf{Alucinación parcial de código:} El chatbot genera código que no coincide exactamente con el del proyecto. \textit{Causa:} El LLM complementa con conocimiento general cuando el contexto RAG recuperado es insuficiente.
			\item \textbf{Navegación incorrecta en visor PDF:} El visor no muestra la página correcta al cambiar de tema. \textit{Causa:} Algunos navegadores no respetan el parámetro \texttt{\#page=N} en iframes por políticas de seguridad.
			\item \textbf{Timeout ocasional (\texttt{HTTP 503}):} El backend responde con un error 503. \textit{Causa:} Render reinicia instancias gratuitas periódicamente; el primer request tras el reinicio activa el arranque frío.
		\end{itemize}
	\end{tcolorbox}
	
	\begin{tcolorbox}[colback=lightgray, colframe=warningred, title=\textbf{5.2 Errores Fatales (Fin abrupto del sistema)}]
		Estas condiciones causan la caída total del servicio afectado y requieren intervención técnica inmediata:
		\begin{itemize}
			\item \textbf{\texttt{GROQ\_API\_KEY} no configurada o expirada:} \textit{Afecta a: Chatbot.} La variable de entorno fue eliminada o la key fue revocada. \textbf{Solución:} Generar nueva key en \texttt{console.groq.com} y actualizar en el dashboard de Render.
			\item \textbf{Repositorio backend o rama \texttt{dev} eliminada:} \textit{Afecta a: Chatbot.} El loader clona \texttt{dev} al iniciar; si no existe, falla la inicialización del RAG. \textbf{Solución:} Restaurar la rama \texttt{dev} en el repositorio original.
			\item \textbf{\texttt{ImportError} en \texttt{chatbot\_logic/}:} \textit{Afecta a: Chatbot.} Actualización incompatible de una dependencia de LangChain durante el redespliegue. \textbf{Solución:} Fijar versiones exactas en el \texttt{requirements.txt}.
			\item \textbf{Build de Vite falla por error de sintaxis JSX:} \textit{Afecta a: Frontend.} Caracteres especiales con codificación incorrecta al editar \texttt{App.jsx}. \textbf{Solución:} Verificar que el archivo se guarde en UTF-8 puro.
			\item \textbf{Puerto no detectado por Render:} \textit{Afecta a: Backend/Chatbot.} El \texttt{Procfile} no expone correctamente \texttt{\$PORT}. \textbf{Solución:} Verificar \texttt{uvicorn app.main:app --host 0.0.0.0 --port \$PORT} en el Procfile.
			\item \textbf{Conflicto de merge no resuelto en \texttt{App.jsx}:} \textit{Afecta a: Frontend.} Push simultáneo de múltiples desarrolladores. \textbf{Solución:} Establecer flujo de trabajo con \textit{feature branches} y \textit{pull requests}.
		\end{itemize}
	\end{tcolorbox}
